# WeathOut ⚡
Do you not know which outfit to put on? Run my script, input your weather, and you will know the outfit. 🌧

## Stack
- Python
- Pandas
- Scikit-learn
- Joblib

## How to use ⚙
1. Download WeathOut.
2. Run main.py in IDE or terminal, not click.
3. Download libraries: 
```py 
pip install pandas scikit-learn joblib
```
4. Input your temperature, wind speed, humidity and rain/snow (1 = yes, 0 = no).
5. Get prediction and put on this outfit.
